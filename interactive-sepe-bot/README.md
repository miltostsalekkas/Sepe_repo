# SEPE bot — interactive case study

A 7-slide Svelte story: why getting a SEPE cita previa is so hard, and how a bot of our own found a free appointment.

```sh
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
```

Navigate with the arrows, the dots, the ← → keys, or by swiping.

All figures and texts live in `src/data.js`; each slide is a component in `src/slides/`.
